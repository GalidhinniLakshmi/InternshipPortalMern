# 🎓 Internship Portal

A full-stack web-based **Internship Portal** developed using the **MERN Stack**.  
The application helps students find internship opportunities, apply for internships, and manage their applications through a user-friendly interface.

## 🚀 Features

### 👨‍🎓 Student Features
- Student Registration and Login
- Secure authentication
- Browse available internships
- View internship details
- Apply for internships
- Track application status
- Manage user profile
- View applied internships

### 🏢 Admin Features
- Admin Login
- Manage internship opportunities
- View registered students
- View internship applications
- Update application status
- Manage portal data
